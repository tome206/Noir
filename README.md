# NOIR – Fragrance Website

NOIR is a fictional fragrance brand website developed as a university project.

The project aims to create a simple online shopping experience for a fragrance brand, allowing visitors to explore products, learn about the brand, and place orders.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Project Purpose

This website was created for educational purposes as part of a university project. It is not a real commercial website.

## Note

NOIR is a fictional brand created for this academic project.
